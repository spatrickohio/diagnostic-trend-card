# Disaster Recovery

TG-WO-2026-004 · November 14, 2026

Recover from a Git bundle or versioned source snapshot if GitHub is down. On lost HA hardware restore a verified backup into compatible Home Assistant and recover sensor integrations. Load the preserved V11 JavaScript and dashboard YAML, map exact entities, then verify statuses. If the Samsung is replaced, reconnect to HA and retest layout. If upstream HA changes frontend interfaces, restore the known-working compatible HA version in an isolated test environment and retain the working baseline. Local card source and configuration allow recovery without OpenAI.
