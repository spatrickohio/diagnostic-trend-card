# Project Overview

TG-WO-2026-004 · November 14, 2026

V11 is a Home Assistant live sensor/status card. It displays formatted values, configurable colors and status badges from threshold rules and sensor availability. The standalone historical trend demo is `docs/index.html`, `app.js`, `style.css` and `sample-data.json`; that demo has separate chart behavior. README mixes earlier prototype history and roadmap. In the tracked V11 card there are no time-series plots, baseline/target overlays, runtime shading, inrush analysis or external notification actions. Baseline/target color keys are supported. An owner configuration or a companion card may provide additional functionality and still needs capture.
