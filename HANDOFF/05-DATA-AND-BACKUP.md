# Data And Backup

The card itself does not own diagnostic data. Save the exact served JS, resource URL/type and dashboard card YAML, entity IDs/units, thresholds and companion automations/recorder settings if applicable. Keep these in the private owner backup. Download a Home Assistant backup covering configuration and required integrations and retain its emergency kit separately if encrypted. A backup drill needs the test instance to reproduce sensor entities or emulate their states.
