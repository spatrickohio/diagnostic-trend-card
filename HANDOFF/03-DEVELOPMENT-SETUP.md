# Development Setup

TG-WO-2026-004 · November 14, 2026

Clone the public repository and check out the pinned commit. Use Node for syntax checks, a modern browser for the standalone demo, and a spare Home Assistant VM or test instance for hardware integration. Record installed HA Core and frontend versions from the owner's system for future compatibility. The V11 file is deployable as plain JavaScript without a package install or bundle step. The repository has no package manifest, lockfile, HACS metadata or test runner.
